## Fixes

- **Pandora artist stations play.** SiriusXM sends station tracks as plain audio files, one per
  track, not as a stream like Xtra channels. Starting a station now queues its tracks (with each
  song's title, artist and artwork), and when the last one starts, the next few are added.
  Save a song you hear on a station with the save button in the player.
- **No more screens of gibberish.** An audio file was being read as a playlist and the error quoted
  it. Errors now never show unreadable data, and audio is never parsed as a playlist.
- **Find stations near me is faster and finds more.** Servers that work are asked first, with
  short timeouts (a server that was down could stall the search for 30 seconds). Besides stations
  listed near you (only some give a location), stations listed in your state are included.
- **No duplicate stations**: the directory lists some stations twice under slightly different
  names; each now shows once.
