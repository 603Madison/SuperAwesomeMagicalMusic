## Security updates

No new features: this release brings the libraries the server, web player and apps are built on up
to versions with known security holes fixed.

- **The server's web layer** (Netty 4.2.20, under Ktor) fixes a critical TLS bypass and several
  ways a crafted request could slip past checks or tie up the server.
- **Logging** (logback 1.5.38), and **Guava 33.7.2** in both Android apps.
- **The web player's router** (React Router 7.18.5) fixes open redirects.

The desktop app is unchanged (only the version number). Update the server first.
