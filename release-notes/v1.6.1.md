## Fixed

- **Saving a song from SiriusXM could save a different version of it.** Matching ignored
  everything in brackets, so "Scarlett" heard on SiriusXM matched "Scarlett (garden version)" in
  Jellyfin. Versions now count: a live, acoustic, remixed or otherwise named version (garden,
  piano, Taylor's…) only matches the same version, while tags like "Remastered", "Explicit",
  "Radio Edit" or featured artists still don't matter. If Jellyfin has only another version, the
  song is saved as heard and plays from Qobuz or YouTube Music. The same applies when finding a
  song on another service to play or download.

  Songs already saved as the wrong version stay as they are: remove them and save them again.
