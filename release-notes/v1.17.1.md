## Server

- **Slowing down password guessing works properly behind Cloudflare and other proxies.** The server
  took a visitor's address from the first `X-Forwarded-For` entry, which the visitor can write
  themselves: someone could get round the per-address limit, or use up yours. Now it uses the
  address your proxy saw. Behind Cloudflare, add `SAMM_CLIENT_IP_HEADER=CF-Connecting-IP`; with
  more than one proxy in a row and no such header, set `SAMM_PROXIES` to how many. The limit per
  account (10 wrong passwords in 15 minutes) was never affected.
