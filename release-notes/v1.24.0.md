## Bold text

A new **Bold text** setting draws all text in Lexend Bold, the way a phone's own Bold text
accessibility setting draws the app. It's off unless you turn it on:

- **SuperAwesomeMagicalMusic app**: Settings › Appearance › Bold text.
- **SuperAwesomeMagicalMusic Lite**: Settings › Appearance › Bold text.
- **Web player**: Settings › Appearance in this browser › Bold text. It applies in that browser
  (sign-in page included) and is remembered there; the page loads only Lexend Bold while it's on.

(The Lite app's home-screen widget keeps its usual weights.)
