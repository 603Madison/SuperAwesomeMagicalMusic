## Pandora thumbs fixed

Thumbs up and down on Pandora stations didn't reach Pandora. SiriusXM turned every thumb down
("HTTP 400"), because the server named the station in a way SiriusXM doesn't accept. The server
still told the player the thumb had worked, so it looked fine and did nothing.

- Thumbs are now sent exactly as SiriusXM's own web player sends them (the station named as
  `{"artistStation": …}`), so they change what the station plays, and they show on your Pandora
  and SiriusXM thumbs lists.
- A thumb SiriusXM turns down no longer looks like it worked. The button goes back as it was and
  says why.
- The server no longer sends SiriusXM a "0 seconds played" report at the start of every station
  song, which SiriusXM always rejected.

This is a fix in the server (and the Lite app, which talks to SiriusXM directly). Update the
server to `ghcr.io/603madison/superawesomemagicalmusic:1.28.1`. The web player and the
SuperAwesomeMagicalMusic app pick it up from there.
