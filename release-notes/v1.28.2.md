## An "Add to F-Droid" button

The repository's page on GitHub now has an **Add to F-Droid** button at the top. Tap it on your
phone and F-Droid opens with the app's repository filled in. Add it, and both apps
(SuperAwesomeMagicalMusic and Lite) install and update from F-Droid. Without F-Droid, the button
opens F-Droid's page for the repository, with a button to add it.

There are no changes to the apps, the web player, the server or the desktop app (only the version
number).
