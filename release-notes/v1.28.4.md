## Up to date underneath

No new features: everything the apps, the web player and the server are built on is now current.

- **Both Android apps:** Media3 1.11 (playback), Room 2.8.5, Coil 3.6 (artwork), the latest
  AndroidX and Compose, OkHttp 5 and NewPipe Extractor 0.27.1 (YouTube Music), built with the
  Android Gradle Plugin 9.
- **Server:** Kotlin 2.4, Ktor 3.6, SQLite 3.54 and logback 1.6.
- **Web player:** React 19.3, hls.js 1.7, lucide icons 1.x, Vite 8 and TypeScript 7.
- The security fixes from 1.28.3 stay in place.

The desktop app is unchanged (only the version number). Update the server first.
