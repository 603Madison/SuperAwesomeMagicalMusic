## YouTube Music on the phone, and Data Saver (again)

- **The quality was still held to 128 kbps on mobile data.** The app saves every setting whenever
  one changes, so 1.19.2's default for "With Data Saver on" (128 kbps) had been saved on phones
  where anything was changed, and 1.20.0's new default never took over. That old value is now
  left behind: "With Data Saver on" is Original unless you choose it again.
- **YouTube Music songs loaded slower than they played on the phone** (in the web player they
  were fine). Two differences from the web player are gone:
  - The phone's player asks for a song's start without a byte range (browsers always send one),
    and YouTube trickles out audio asked for that way. Your server now always asks YouTube with
    a range.
  - At 128 kbps the phone got YouTube's AAC copy, where the web player gets Opus; with the
    Data Saver cap gone, the phone gets the same copy as the web player again.
- **Songs come through your server again by default**, as in the web player. 1.20.0's "Get
  YouTube Music on this phone" (Settings › Quality) is now off unless you turn it on: it's for
  when your server can't reach YouTube, and starts more slowly.
- **The details say "Being picked by your server…"** while a song's copy is still being chosen,
  instead of showing nothing.

## Stream test

- For a YouTube Music song, **the web player's "Test this song's stream from your server"** now
  tries every copy YouTube offers (Opus and AAC, each bitrate), reading each for a few seconds
  the way a browser does, and says how fast each came.
