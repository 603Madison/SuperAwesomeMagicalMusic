## Quality on mobile data: no more Data Saver guessing

- **Songs were held to the "With Data Saver on" quality with Data Saver off.** Android can't
  tell an app whether Data Saver is on: it gives the same answer when the app's own
  "Background data" setting is off, which is what this phone reported. The app can't tell the
  two apart, so it no longer follows Data Saver at all, and **"With Data Saver on" is gone from
  Settings › Quality**. Your choice for mobile data is what applies there; to save data on
  mobile, choose a lower quality for "On mobile data".
- **The (i) details say which choice set the quality cap** (your choice for Wi-Fi, mobile data
  or satellite).

(The SuperAwesomeMagicalMusic app only; the server and the Lite app are unchanged.)
