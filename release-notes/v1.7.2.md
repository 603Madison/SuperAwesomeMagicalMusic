## Security

- **Other apps can no longer read your library through the media service.** Any installed app
  could connect to the app's media service (the one Android Auto uses) and browse your
  playlists and downloads, run searches with your accounts, or queue songs. Now only the system
  (media controls, Bluetooth), apps Android trusts with media control, Android Auto, Android
  Automotive, the Assistant and Wear OS get that; other apps only get play, pause and skip.
- **Lidarr's API key and the Qobuz token no longer follow redirects to other servers.** If a
  server redirected a request elsewhere (to a sign-in page in front of a home server, say),
  these headers went along; now they're dropped, as the standard Authorization header already was.
- **Signing out of Nextcloud revokes the app password** on the server, rather than only
  forgetting it on the phone.
- **Downloaded file names can't be steered by a server.** The file extension a server reports
  is now limited to letters and digits.

## Fixed

- **SiriusXM requests no longer wait on each other.** Every SiriusXM request held one lock for
  its whole round trip, so a slow one (telemetry or a search, especially on satellite) held up
  the stream key the player needed next and could stall playback. Only signing in waits now.
- **Renaming a playlist while it synced could undo the rename.** The sync wrote back its older
  copy of the playlist; it now only records the sync details.
- **The app log rewrote its whole file for every line** once full (often on the main thread);
  it now appends, trims occasionally, and writes in the background.
- **Lidarr retries:** while Lidarr is unreachable (away from home), each new artist no longer
  triggers another connection attempt; requests wait in the queue and go out on the next network
  change or after a few minutes.
- Android Auto's buttons are only sent again when they change, and player actions made before
  the app finished connecting to the player all run, not just the last one.
