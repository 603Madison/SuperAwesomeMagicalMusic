## Fixes

- **SiriusXM Xtra channels play past the intro again.** Tuning an Xtra channel returns a queue
  of several tracks; only the first (the intro) was played. Every track in the queue is now
  played, and when it runs low the app asks for more with SiriusXM's own "peek" request, as
  SiriusXM's web player does. Each finished track is reported as played through.
- **Pandora artist stations** use the same queue, so stations keep playing too.
- **Artist search works**: it now sends the same request as SiriusXM's web player, and finds
  artists' Pandora stations directly (listed first).
- **Find stations near me works**: the radio directory's DNS can point at a server that's down,
  which made every search fail with "connection closed". The app now falls back to the other
  servers.
