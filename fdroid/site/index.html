The repository has both apps: SuperAwesomeMagicalMusic, for your own SuperAwesomeMagicalMusic server, and SuperAwesomeMagicalMusic Lite, which works on its own with no server (it was called SuperAwesomeMagicalMusic until 1.11.0). They install side by side.

F-Droid updates an app you installed from a GitHub release too: every version is signed with the same key, so nothing needs reinstalling.
